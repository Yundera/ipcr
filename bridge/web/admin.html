Health

IPNS record

The record must be renewed by this node while it is online (Kubo does it every 4 h). Lifetime is how long a record stays valid if this node goes offline; TTL is how long resolvers cache it.

Storage

    Root organisation

    The public repositories of this Gitea organisation are also published at the root of the forge's name: metadec/app → …/ipns/<name>/app. Its members (Gitea teams) are the ones who can publish there. Leave empty for none.

    Which repositories may publish

    Each public repository switched on here publishes under its own name only: the forge sets an IPCR_PUSH_TOKEN secret on it, and the staging registry accepts that token for that name and no other. Workflows log in with it (see the forge page's template). New public repositories are on.

    Key backup

    Download a backup

    The key, encrypted with your passphrase (at least 12 characters). Keep the file and the passphrase apart. Without a backup, losing this server loses the name for good.

    Restore a backup

    Makes the backed-up key this forge's publisher key: to move a forge to a new server, or recover one. The current key is kept (renamed), not deleted.

    Every image name then points at this server's images under the restored name. On a fresh server, the name's last published images are adopted.
