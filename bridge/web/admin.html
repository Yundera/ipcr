Key backup

Download a backup

The key, encrypted with your passphrase (at least 12 characters). Keep the file and the passphrase apart. Without a backup, losing this server loses the name for good.

Restore a backup

Makes the backed-up key this forge's publisher key: to move a forge to a new server, or recover one. The current key is kept (renamed), not deleted.

Every image name then points at this server's images under the restored name. On a fresh server, the name's last published images are adopted.
